파란 줄과 배열의 변화를 함께 따라가세요.

  1. def binary_search(arr, target):
  2. low = 0
  3. high = len(arr) - 1
  5. while low <= high:
  6. mid = (low + high) // 2
  8. if arr[mid] == target:
  9. return mid # 찾음! 위치를 반환
  10. elif arr[mid] < target:
  11. low = mid + 1 # 오른쪽 절반만 남김
  12. else:
  13. high = mid - 1 # 왼쪽 절반만 남김
  15. return -1 # 없음

arr는 정렬된 배열, target은 찾을 숫자예요. low와 high는 각각 왼쪽(L)·오른쪽(R) 경계이고, // 2는 2로 나눈 몫을 구해요.

아직 비교하지 않았어요.
‘한 단계 →’를 누르면 첫 번째 비교가 기록돼요.

    왜 이렇게 빠를까요?

    한 번 비교할 때마다 가운데 값과 필요 없는 절반을 제외할 수 있어요.

    15 → 7 → 3 → 1

    15개의 숫자는 최대 4번 비교하면 찾거나, 없다는 것을 알 수 있어요.

    −999부터 999까지 정수를 1~31개 넣을 수 있어요. 오름차순으로 자동 정렬해요. 중복된 숫자는 그중 하나를 찾습니다.
